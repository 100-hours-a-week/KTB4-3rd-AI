# 외부 의존

## 이미지 다운로드(image_fetch) 규칙

판독 요청의 image_URL(예: presigned URL)을 서버가 GET으로 받는다. receipt와 taxi_meter의 image.py는 같은 규칙을 쓴다.

| 항목 | 값 | 코드 |
| --- | --- | --- |
| 전체 시간 상한 | 5.0초(연결·읽기 전체를 asyncio.wait_for로 묶음) | TIMEOUT |
| 리다이렉트 | 따라가지 않음(follow_redirects=False). 3xx는 실패 | - |
| 크기 상한 | 5MB(5 × 1024 × 1024바이트). 받는 도중 넘으면 바로 중단 | MAX_SIZE |
| 허용 형식 | image/jpeg, image/png. 파일 내용(Pillow)으로 판단 | ALLOWED |
| 재시도 | 없음 | - |

- 실패하면 422 IMAGE_FETCH_FAILED(다운로드), IMAGE_SIZE_INVALID(0바이트·5MB 초과), IMAGE_TYPE_INVALID(이미지 아님·형식 다름)다.
- 로그에는 URL 호스트만 남긴다. presigned 쿼리스트링은 저장하지 않고, 모니터는 URL 쿼리스트링을 마스킹한다.
- 다운로드 실패 사유(reason): timeout, connect, redirect, http_4xx, http_5xx, bad_url.
- 훈련(drill) 요청에서는 주입 플래그 drill.image_fetch가 있으면 실제 다운로드 대신 지정 상태 코드(기본 403) 실패를 만든다(local·dev만).

## OpenAI(luna) 호출 값

app/llm/providers/openai.py 기준이다.

| 항목 | 값 |
| --- | --- |
| 엔드포인트 | OpenAI Responses API(`https://api.openai.com/v1/responses`) |
| 모델 | gpt-6-luna(코드 고정) |
| 키 | 이미지 기능은 OPENAI_API_KEY_1, 없으면 OPENAI_API_KEY |
| 구간 상한(재시도 포함) | 45초(TIMEOUT) |
| 재시도 대상 | 429, 5xx만 |
| 최대 시도 | 2회 |
| 재시도 대기 | 1.0초(RETRY_WAIT) |
| 재시도 조건 | 대기 뒤 남은 시간이 10초(RETRY_MIN) 이상일 때만 |

- 키가 없으면 호출하지 않고 503 MODEL_NOT_READY를 낸다.
- HTTP 오류·시간 초과는 502 UPSTREAM_FAILED, 응답에 output_text가 없거나 형식이 다르면 역시 502(reason shape)다.
- 남기는 값: 상태 코드, 오류 본문의 error.type/error.code, 응답 헤더 x-request-id, 입출력 토큰 수. 오류 메시지 원문은 남기지 않는다.
- 45초는 실측(2026-10-15, 75회) 최대 30.4초의 1.5배다.

## OpenAI 호출 조정 플래그

모니터 조정이 바꿀 수 있는 공유 플래그가 openai.py에서 읽힌다.

- `llm.max_concurrency`: 0 이하면 동시 호출 제한 없음. 1 이상이면 그 수의 세마포어로 동시 호출을 묶는다. 자리 대기는 "남은 시간 - 10초"까지이고, 넘기면 502 UPSTREAM_FAILED(reason concurrency_wait)다.
- `image.max_side_px`: 0 이하면 원본 그대로 보낸다. 값이 있으면 긴 변이 그 값을 넘는 이미지를 비율대로 줄여 보낸다(PNG는 PNG, 그 밖은 JPEG로 다시 저장).
- 훈련(drill) 요청에서는 주입 플래그 drill.luna_call이 있으면 실제 호출 대신 지정한 지연·상태 코드(기본 429)·오류 코드(기본 rate_limit_exceeded) 응답을 만든다(local·dev만).

## Modal 호출 값

app/llm/providers/modal_gpu.py 기준이다. GPU 경로(DEVICE=modal)에서만 쓴다.

| 항목 | 값 |
| --- | --- |
| 토큰 | MODAL_TOKEN_ID_1, MODAL_TOKEN_SECRET_1(_1 이미지 계정) |
| 앱 이름 | `oj-image-models-<코드 해시 12자>` |
| 클래스 | OjModels, 메서드 pipe |
| 작업 1건 대기 상한 | 15초(WAIT). 공유 플래그 modal.wait_s로 바꿀 수 있음 |
| 원격 작업 실행 상한 | 120초(modal_app.py timeout) |
| 재시도 | 없음. 실패하면 luna로 넘김 |

- 호출은 spawn 후 결과를 대기 상한까지 기다린다. 넘기면 luna로 넘어가고, 원격 호출은 취소되지 않고 계속 돌아 컨테이너를 데운다.
- 실패 사유(reason): 이름에 Timeout이 들어가면 timeout, AuthError → auth, NotFoundError → not_found, ResourceExhaustedError → quota, PermissionDeniedError → permission, 그 밖은 remote_error.
- 상태가 ready가 아니면(배포 중·down) 기다리지 않고 바로 luna로 넘긴다.

## 외부 연결 경로와 담당

클라우드 전달 문서의 네트워크 경로와 역할 분담 기준이다.

| 목적지 | 포트 | 용도 |
| --- | --- | --- |
| api.openai.com | TCP 443 | 판독(luna)과 모니터 진단·답변 LLM, 임베딩 |
| api.telegram.org | TCP 443 | 알림 발송, 명령 수신(Long Polling) |
| 운영 RDS(AI 전용 DB) | TCP 3306(TLS) | 모니터 기록 적재·조회, 리더 선출 잠금 |
| Qdrant | TCP 6333(HTTP, API 키) | 지식·문서·대화 벡터 검색 |
| CloudWatch Logs API | TCP 443 | 원본 로그 보조 조회(dev·prod 읽기) |

| 담당 | 범위 |
| --- | --- |
| 클라우드팀 | RDS 내 AI 전용 DB·계정·권한, Qdrant 구축·운영·백업 설정, 보안그룹, SSM 파라미터(DB·Qdrant)와 ECS 태스크 정의 연결 |
| AI 담당자 | DB 스키마 생성·변경과 초기 데이터 적재, 스테이지별 연동 테스트, 연결 상태·용량 점검, 텔레그램 봇 운영(토큰 스테이지 전환 포함) |

- 키 담당(환경변수 안내 문서): OPENAI_API_KEY_1·MODAL_TOKEN_*_1은 이미지 담당, OPENAI_API_KEY_2·MODAL_TOKEN_*_2는 혼잡도 담당.
- 이미지 저장소(presigned URL 발급 쪽)의 담당은 근거 문서에 적혀 있지 않다.

## 모니터 저장소 연결 값

클라우드 전달 문서와 store/vector.py 기준이다.

| 항목 | 값 |
| --- | --- |
| MySQL 버전 | 8.0.19 이상(8.4 권장) |
| MySQL 태스크당 연결 | 평시 최대 3개(풀 2 + 리더 잠금 1), 배포 직후 일시 1개 추가 |
| MySQL 타임아웃 | 연결 5초, 읽기·쓰기 10초 |
| MySQL 재연결 | 간격을 2배씩 늘려 최대 60초 + 무작위 지연 |
| MySQL TLS | `?ssl=verify`, RDS 공식 CA 번들 사용 |
| Qdrant 클라이언트 | qdrant-client 1.20.0 고정, 서버는 마이너 버전 차이 1 이하 권장(qdrant/qdrant:v1.20.0) |
| Qdrant 포트 | 6333(HTTP REST)만. 6334(gRPC) 불필요 |
| Qdrant 클라이언트 타임아웃 | 10초 |
| Qdrant 인증 | API 키 필수(읽기·쓰기) |

- AI DB나 Qdrant가 중단돼도 API 서비스는 영향이 없다. RDS 접속 불가 때 수집 기록은 컨테이너 버퍼에 보관했다가 복구 후 다시 보낸다.
