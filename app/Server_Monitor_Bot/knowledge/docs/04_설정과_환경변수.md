# 설정과 환경변수

## 판독 서비스 환경변수

이름과 용도만 적는다. 값은 이 문서에 두지 않는다. `_1`은 이미지(택시미터·영수증), `_2`는 혼잡도이며 키와 Modal 계정을 서로 나눈다(fastapi-env-guide.md, app/core/config.py, app/llm/providers/openai.py).

| 변수 | 용도 | 담당(안내 문서 기준) |
| --- | --- | --- |
| OPENAI_API_KEY_1 | 이미지용 OpenAI 키(/taxi_meter, /receipt) | 이미지 담당 |
| OPENAI_API_KEY | 예전 이름. OPENAI_API_KEY_1이 없을 때 대신 읽음 | - |
| OPENAI_API_KEY_2 | 혼잡도용 OpenAI 키 | 혼잡도 담당 |
| ANTHROPIC_API_KEY | 혼잡도 폴백(haiku)용 Anthropic 키. 혼잡도 코드가 쓴다 | 혼잡도 담당 |
| LOCAL_DEVICE | 이 서버에서 OCR·openjev를 직접 돌릴지(TRUE/FALSE). 로컬 테스트용 | 이미지 담당 |
| MODAL_TOKEN_ID_1, MODAL_TOKEN_SECRET_1 | 이미지용 Modal 토큰. 둘 다 있으면 GPU 경로가 Modal | 이미지 담당 |
| MODAL_TOKEN_ID_2, MODAL_TOKEN_SECRET_2 | 혼잡도용 Modal 토큰 | 혼잡도 담당 |

- 더 이상 읽지 않는 예전 변수: IMAGE_DEVICE, OPENAI_MODEL_1/2, 번호 없는 MODAL_TOKEN_ID/SECRET. 남아 있어도 영향이 없다. (Dockerfile 주석에는 IMAGE_DEVICE가 남아 있지만 코드는 읽지 않는다.)
- 정상 기동 확인: `GET /health` → `{"status":"ok"}`

## 이미지 처리 장치(DEVICE) 결정 순서

app/core/config.py의 resolve_device()가 기동 때 한 번 정한다.

1. MODAL_TOKEN_ID_1과 MODAL_TOKEN_SECRET_1이 둘 다 있으면 `modal`
2. 아니고 LOCAL_DEVICE가 TRUE(대소문자 무시)면 이 서버의 cuda → mps → cpu 중 쓸 수 있는 것. torch가 없으면 cpu
3. 둘 다 아니면 `off`: 이미지 모델 없이 항상 luna(OpenAI)로 처리. 기본값

- 설치: 기본 설치만 하면 off(luna만) 경로로 동작한다. LOCAL_DEVICE=TRUE에는 `.[local]` 설치가 필요하다.
- Modal이나 로컬 모델을 켰는데 패키지·토큰이 없으면 기동 때 한 번 경고하고 luna로 처리한다.
- config.py 주석은 "Modal T4"라고 적혀 있지만 실제 Modal 앱 GPU는 L4다(llm/modal_app.py).

## 모니터 봇 환경변수

app/Server_Monitor_Bot/config/settings.py가 읽는 이름이다. 값은 두지 않는다.

| 변수 | 용도 |
| --- | --- |
| AI_DB_URL | AI 전용 MySQL 접속 URL. DB 이름(ai_<stage>)으로 스테이지를 정한다 |
| AI_QDRANT_URL | Qdrant 접속 주소(포트 6333) |
| AI_QDRANT_API_KEY | Qdrant API 키(읽기·쓰기) |
| TELEGRAM_BOT_TOKEN | 텔레그램 봇 토큰 |
| Admin_Telegram_ID | 관리자 텔레그램 사용자 ID. 숫자, 여러 명이면 쉼표로 구분. 민감 정보 아님 |
| DISCORD_BOT_TOKEN | 디스코드 봇 토큰. 비우면 디스코드는 꺼지고 텔레그램만 쓴다 |
| DISCORD_CHANNEL_ID | 알림을 보내고 메시지를 받을 디스코드 채널 ID. 민감 정보 아님 |
| Admin_Discord_ID | 관리자 디스코드 사용자 ID. 숫자, 여러 명이면 쉼표로 구분. 민감 정보 아님 |
| DRILL_IMAGE_URL | 선택(기본 env 목록 밖). 장애 훈련 합성 요청에 쓸 테스트 이미지 URL(dev·local) |
| OPENAI_API_KEY_MONITOR | 선택(기본 env 목록 밖). 모니터용 OpenAI 키. 없으면 OPENAI_API_KEY_1, 그것도 없으면 OPENAI_API_KEY |
| SERVER_BOT_DIR | 선택(기본 env 목록 밖). 컨테이너 버퍼 폴더. 없거나 비어 있으면 /tmp/server_bot |

- AI_DB_URL 형식: `mysql://<계정>:<비밀번호>@<호스트>:3306/ai_<stage>?ssl=verify`. 비밀번호의 특수문자는 퍼센트 인코딩한다.
- 클라우드 전달 문서 기준 OpenAI는 기존 OPENAI_API_KEY_1을 그대로 쓰며 추가 발급이 없다.
- AI_QDRANT_URL이 없으면 local 스테이지만 `http://localhost:6333`로 대신하고, 다른 스테이지는 오류로 처리한다(store/vector.py).

## 스테이지 판정과 SSM 경로

- 스테이지는 AI_DB_URL의 DB 이름으로 정한다. 허용 이름: `ai_local`, `ai_dev`, `ai_stg`, `ai_prod`.
- DB 이름이 이 형식이 아니면 모니터가 켜지지 않는다(`monitor disabled: reason=db_name`). API 서비스에는 영향이 없다.
- 배포 환경의 런타임 값은 이미지에 넣지 않는다. ECS 태스크가 SSM에서 주입한다.
- SSM 경로 패턴: `/moyeota/v2/<stage>/ai/<변수 이름>`
  - 예: `/moyeota/v2/<stage>/ai/AI_DB_URL`, `/moyeota/v2/<stage>/ai/AI_QDRANT_API_KEY`, `/moyeota/v2/<stage>/ai/TELEGRAM_BOT_TOKEN`
- DB 비밀번호와 API 키 등 민감 정보는 메신저나 문서로 공유하지 않고 SSM SecureString으로만 관리한다.
- TELEGRAM_BOT_TOKEN은 동시에 1개 스테이지만 활성화한다(dev → stg → prod 순으로 검증 후 최종 prod 고정).

## config.toml 스테이지 스위치

모니터 설정 파일은 app/Server_Monitor_Bot/config/config.toml이다. 시크릿은 환경변수, 나머지는 이 파일에서 고친다.

| 스테이지 | enabled | drill | F1~F7 | F8 | F9 |
| --- | --- | --- | --- | --- | --- |
| local | true | true | true | true | true |
| dev | true | true | true | true | true |
| stg | true | false | true | false | true |
| prod | true | false | true | false | true |

이벤트와 기능 스위치 대응(ops_agent/events.py FEATURE)이다.

| 스위치 | 대상 |
| --- | --- |
| F2 | 장애 감지 후 진단(alert.pipeline) |
| F3 | 일반 대화(user.message) |
| F4 | /trace 요청 추적(user.trace) |
| F5 | 지식 편집, [저장]·[취소] |
| F7 | 조정 제안·적용·관찰, 거절·즉시 원복 |
| F8 | 훈련 /drill start·stop·guess |
| F9 | /status, /flags, /knowledge, /help, /join, /request, 가입 승인·거절 |

- F1, F6은 이 대응표에 없다. 대응표에 없는 이벤트는 F9로 본다.
- 스위치가 꺼진 기능을 부르면 "이 기능은 <stage>에서 꺼져 있습니다"로 답한다.

- 감지(P3)는 15초마다 최근 5분(300초) 창을 본다.
- 사람 메시지 대기열은 20건까지 받고, 같은 사람의 같은 글은 60초 안에 다시 받지 않는다. 알림·후속 이벤트는 사람 메시지보다 먼저 처리한다.
- 지식 정리본은 24시간 유효하다. 조정 적용 뒤 600초 뒤에 효과를 본다.
- 검색 점수(코사인)가 기준보다 낮은 결과는 버린다. 문서는 미리 3절까지 찾고 같은 문서에서 2절까지만 쓴다.
- 대화 문맥은 원문 추정 토큰이 8000을 넘으면 오래된 턴을 요약에 합쳐 4000 이하로 줄인다.

- buffer.max_mb = 50: 컨테이너 SQLite 버퍼 크기 상한(MB)

- `[policy."<knob>"]` 섹션: 조정 정책 표. min, max, default, max_ttl_min, prod_ok를 둔다(07_조정_정책표 참고).
