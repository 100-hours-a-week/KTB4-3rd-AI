# 조정 정책표

## 정책표 개요

모니터 봇이 서비스 동작을 잠깐 바꿀 수 있는 조정 항목(knob)과 범위다. config.toml의 `[policy."<knob>"]` 섹션이 원본이다.

| knob | 한글 이름 | min | max | default | max_ttl_min | prod_ok |
| --- | --- | --- | --- | --- | --- | --- |
| llm.max_concurrency | LLM 동시 호출 상한 | 1 | 8 | 0 | 60 | true |
| image.max_side_px | 이미지 최대 변 길이 | 1024 | 2048 | 0 | 120 | false |
| route.force_luna | luna 강제 전환 | 1 | 1 | 0 | 30 | true |
| modal.wait_s | Modal 대기 시간 | 10 | 30 | 15 | 60 | true |

- default는 조정이 없을 때 값이다. 조정 값은 공유 플래그(runtime_flags)에 들어가고 만료되면 지워져 default로 돌아간다.
- prod_ok=false인 knob은 prod에서 제안하지 않는다.
- 정책표에 없는 키는 지식의 policy_key로 쓸 수 없다(knowledge/schema.py validate).

## llm.max_concurrency(LLM 동시 호출 상한)

- 뜻: 판독 서비스가 OpenAI(luna)를 동시에 부르는 수의 상한(app/llm/providers/openai.py).
- 값 0(default) 또는 0 이하: 제한 없음. 텔레그램에는 "제한 없음"으로 보인다.
- 값 1~8: 그 수의 세마포어로 묶는다. 자리를 기다리다 "남은 시간 - 10초"를 넘기면 502 UPSTREAM_FAILED(reason concurrency_wait).
- 제안 지침(adapt/prompts.py): 최근 30분 동시 처리 최대치보다 작게, 대개 절반 근처.
- 범위 1~8, 최대 유지 60분(prod 30분), prod 허용.

## image.max_side_px(이미지 최대 변 길이)

- 뜻: luna로 보내기 전 이미지의 긴 변을 이 값 이하로 비율대로 줄인다(openai.py resize).
- 값 0(default): 줄이지 않는다.
- 범위 1024~2048, 최대 유지 120분.
- prod_ok=false: prod에서는 제안하지 않는다(사유 "prod 금지").

## route.force_luna(luna 강제 전환)

- 뜻: GPU 큐로 간 요청도 Modal·로컬 모델을 쓰지 않고 luna로 처리한다(features/*/main.py run_gpu, route_reason force_luna).
- 범위 min=max=1. 적용할 때 플래그 값은 true로 넣는다(adapt/nodes.py apply).
- 최대 유지 30분(prod 15분), prod 허용.
- V3 전용: 서비스 DEVICE가 off면 제안하지 않는다(사유 "이 환경에서 의미 없음").

## modal.wait_s(Modal 대기 시간)

- 뜻: GPU 경로에서 Modal 작업 1건 결과를 기다리는 상한(초). 넘기면 luna로 넘긴다(llm/providers/modal_gpu.py).
- default 15: 코드 상수 WAIT와 같다. 주석상 BE 60초 - 이미지 다운로드 10초 - luna 30초 - 여유 5초.
- 범위 10~30, 최대 유지 60분(prod 30분), prod 허용.
- V3 전용: DEVICE가 off면 제안하지 않는다.

## 값과 TTL 강제 규칙

adapt/policy.py의 clamp와 max_ttl 규칙이다.

- 값은 [min, max] 안으로 자른다.
- prod에서 기준값(baseline)이 있으면 값은 `ceil(baseline × 0.5)` 이상이어야 한다(그래도 max 이하).
- 최대 유지 시간: prod는 max_ttl_min의 절반, 그 밖은 max_ttl_min 그대로.
- 유지 시간(ttl_min)은 1분 이상, 최대 유지 시간 이하로 자른다. 비어 있으면 최대 유지 시간을 쓴다.
- 기준값: 현재 조정 값이 있으면 그 값, 없으면 최근 30분 동시 처리 최대치(inflight).
- 제안 작성이 실패하면 기본 제안: 값 = max(min, 기준값 // 2), 유지 = 최대 유지 시간.

## 제안이 생기는 조건과 건너뛰는 조건

제안(S4a)은 두 곳에서 시작한다.

- 즉시 알림: 감지(P3)가 맞춘 지식이 alert=immediate이고 policy_key가 있으며 훈련이 아닐 때 signal.policy 이벤트를 낸다.
- 진단: 진단 결과의 policy_key가 정책표에 있고 훈련이 아닐 때 조정 요청으로 이어진다.

다음이면 제안하지 않는다(adapt/nodes.py match).

| 사유 | 조건 |
| --- | --- |
| 정책 없음 | policy_key가 정책표에 없음 |
| 이 환경에서 의미 없음 | route.force_luna·modal.wait_s인데 DEVICE가 off |
| prod 금지 | prod이고 prod_ok=false |
| 같은 knob 활성 | 같은 knob이 applied·kept 상태이거나, 24시간 안에 만든 proposed가 있음 |

## 승인과 적용 흐름

1. 제안: adjustments에 status=proposed로 기록하고 텔레그램에 "⚙️ 조정 제안 · <knob>, <현재> → <새 값> · <분>분 유지, 근거"와 [승인][거절] 버튼을 보낸다.
2. [거절]: status=rejected, 플래그는 바뀌지 않는다.
3. [승인]: 한 트랜잭션에서 proposed → applied로 바꾸고 runtime_flags에 값과 만료 시각(지금 + ttl_min분)을 넣는다. 직전 10분 지표를 before로 저장한다. 실패하면 1·2·4초 간격으로 다시 시도하고, 끝내 실패하면 "잠시 뒤 [승인]을 다시 눌러 주세요"로 답한다.
4. 적용 메시지: "⚙️ 조정 적용 · <knob>, <이전> → <새 값> · <시각>까지 (<분>분), 10분 뒤 효과를 보고합니다"
5. 관찰: observe_after_s(600초) 뒤 적용 시각부터 10분 지표를 before와 비교해 판정한다.

- [승인]·[거절]·[즉시 원복]은 관리자와 승인된 팀원 모두 누를 수 있다(roles.py ADMIN_ONLY에 없음).
- 서비스는 공유 플래그를 컨테이너 SQLite 캐시에서 3초 메모리 캐시로 읽는다. 플래그 동기화(P8)가 3초마다 runtime_flags를 이 캐시로 복사한다.

## 효과 판정과 결과 처리

adapt/policy.py verdict 규칙이다(위에서부터 먼저 맞는 것).

| 조건 | 판정 |
| --- | --- |
| 적용 후 호출 수 < 5 | no_effect |
| 적용 후 p95 ≥ 적용 전 p95 × 1.3 | worse |
| 적용 전 실패율 0이고 적용 후 실패 ≥ 3 | worse |
| 적용 전 실패율 0(그 밖) | no_effect |
| 실패율 변화 ≥ +10%이고 (호출 ≥ 20 또는 실패 ≥ 3) | worse |
| 실패율 변화 ≤ -20%이고 실패 수가 줄어듦 | improved |
| 그 밖 | no_effect |

| 판정 | 상태 | 처리 |
| --- | --- | --- |
| improved | kept | 유지. TTL이 끝나면 자동 원복 |
| no_effect | applied | 유지. 결과 메시지에 [즉시 원복] 버튼 |
| worse | rolled_back | 바로 원복(플래그 삭제) |

## 만료와 원복

- 만료: 플래그 동기화(P8)가 모든 태스크에서 3초마다 만료 시각이 지난 플래그를 지운다. 연결된 조정은 status=expired가 되고 "⏱ 조정 만료 · 원래 값으로 되돌렸습니다" 메시지를 보낸다.
- [즉시 원복]: applied·kept 상태 조정을 rolled_back으로 바꾸고 그 플래그를 지운다. 되돌릴 조정이 없으면 "되돌릴 활성 조정이 없습니다".
- /flags 명령으로 활성 조정(knob, 값, 만료 시각, 설정 주체)을 본다.
- adjustments 상태 값: proposed, rejected, applied, kept, rolled_back, expired.
