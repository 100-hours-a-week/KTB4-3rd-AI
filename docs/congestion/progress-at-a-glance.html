  • 연동 문서의 예시 요청으로 양쪽 로그와 결과를 함께 확인한다.

팀과 먼저 정할 것

데이터와 시간

  • 출퇴근 시간의 시작·끝, 기준 시간대, 10분↔60분 전환 시 첫 조회 범위
  • 수정·삭제된 글과 오래된 부모 글의 새 댓글을 어떻게 조회할지
  • 작성자 식별자 author_key와 스팟 배정 기준

실패와 운영

  • 스팟 FAILED, 요청 전체 422·5xx, 응답 유실 시 이전 결과 처리
  • 요청량·최대 입력량, Spring 대기시간, 중복·역순 응답 처리
  • 서버 간 인증, 실제 호출 URL, 요청 추적 ID

세부 필드와 JSON 예시가 필요하면 Spring 연동 문서를 그대로 전달하면 됩니다. 이 페이지는 업무 판단용 요약입니다.
