# 모니터봇 사용법

## /trace 요청 추적

- 사용: `/trace <request_id>`. request_id는 응답 헤더 X-Request-ID 값이고 서버 로그의 `request_id=`와 같다.
- 모니터가 기록한 요청 결과(request_results)와 그 요청의 LLM 호출(llm_calls)을 근거로 챗봇이 답한다.
- 요약 내용: 기능, 결과(ok·fail), 응답 코드, 단계(step_id), 사유(reason), 처리 경로(route와 사유), 지연 시간(ms), LLM 호출 수.
- 기록이 없으면 "<request_id> 기록 없음(30일 보존, 사용자 단위 추적 안 함)"이다.
- 알림 메시지의 "샘플: /trace <id>" 줄에서 바로 쓸 수 있다.
- 기능 스위치 F4가 켜진 스테이지에서만 동작한다.
